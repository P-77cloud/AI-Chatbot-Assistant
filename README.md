

An AI-powered chatbot assistant built using **n8n workflow automation** and **OpenAI GPT-5 mini**. It provides automated conversational responses through an interactive chat interface.

## 🚀 Features

- 💬 Interactive chatbot interface
- 🧠 AI-powered responses using OpenAI GPT-5 mini
- 🤖 AI Agent for processing user messages
- 🔄 Automated workflow execution using n8n
- 📝 Conversation context using Simple Memory
- 🌐 Public chatbot access

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| n8n | Workflow automation |
| OpenAI GPT-5 mini | AI language model |
| AI Agent | Conversational processing |
| Simple Memory | Conversation context |

## 🏗️ Workflow Architecture

The chatbot follows this workflow:

1. **Chat Trigger:** Receives messages from users.
2. **AI Agent:** Processes the incoming messages.
3. **OpenAI Chat Model:** Generates intelligent responses using GPT-5 mini.
4. **Simple Memory:** Maintains conversation context.
5. **Chat Interface:** Displays responses to users.

## ⚙️ Setup Instructions

1. Install or access an n8n instance.
2. Download the workflow JSON from this repository.
3. Import the JSON workflow into n8n.
4. Configure your own OpenAI credentials.
5. Activate the workflow.
6. Open the chatbot URL and start interacting.

## 🔐 Security

- Never upload API keys or private credentials.
- Configure OpenAI credentials securely inside n8n.
- Protect public chatbot endpoints against excessive usage.
- Avoid sharing sensitive personal information through the chatbot.

The objective of this project is to explore AI-powered conversational systems and understand how workflow automation tools can integrate with large language models to build practical AI applications.
